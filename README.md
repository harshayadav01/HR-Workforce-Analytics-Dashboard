# HR Workforce Analytics Dashboard

## Project Overview

The HR Workforce Analytics Dashboard is an interactive Microsoft Excel project designed to transform raw employee data into meaningful business insights. It provides a comprehensive view of workforce metrics, helping HR professionals and business stakeholders analyze employee demographics, compensation, hiring trends, performance, and bonus eligibility through dynamic visualizations.

---

## Problem Statement

Organizations often manage large volumes of employee data across multiple departments and locations. However, extracting meaningful insights from this data can be challenging without an effective reporting solution. Traditional reports make it difficult to monitor workforce trends, compare departmental performance, and evaluate key HR metrics efficiently.

This project addresses these challenges by developing an interactive HR Workforce Analytics Dashboard in Microsoft Excel. The dashboard consolidates key workforce metrics into a single, easy-to-use interface, enabling users to monitor employee distribution, analyze salary trends, evaluate hiring patterns, assess performance, and support data-driven decision-making.

---

## Business Objectives

- Monitor key workforce KPIs.
- Analyze employee distribution across departments and cities.
- Compare average salaries by department.
- Track hiring trends over multiple years.
- Evaluate employee performance distribution.
- Analyze bonus eligibility across the workforce.
- Support HR reporting through interactive filtering and visualizations.

---

## Dataset Information

The dataset consists of **5,000 employee records** containing workforce-related information such as employee demographics, salary details, department, city, joining date, performance ratings, attendance, and bonus eligibility.

### Key Fields

- Employee ID
- Employee Name
- Gender
- Department
- Designation
- City
- Joining Date
- Salary
- Bonus
- Attendance
- Performance Rating
- Manager Details
